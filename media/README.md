# 一分钟项目介绍

`source2brain-intro-60s.mp4` 来自现有 120 秒 V4 介绍片，视频时间轴缩短为一半，音频以 `atempo=2` 加速并保留音高；1080×1920、30fps、约 60 秒。`source2brain-intro-60s.srt` 同步将字幕时间除以二。

README 的四张 PNG 来自同一成片的关键帧：微信结果、画面证据、新会话回读与最后的工具箱主旨。未合成新的成功消息，界面示意和验证状态标注保留。

视频为项目介绍，包含已验证结果的界面示意与来源片段；实际能力范围以 [v0.2 验证矩阵](../docs/v0.2-validation.md) 为准。动画、音效与来源素材不构成对第三方素材权利的再授权。

视频独立于运行包分发，安装 Source2Brain 不需要下载制作工程或媒体。
