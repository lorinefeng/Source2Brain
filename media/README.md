# 38 秒项目介绍

`source2brain-intro.mp4`：720×1280、30fps、约 38 秒，H.264 + AAC，适合在 GitHub 直接播放。`source2brain-intro.srt` 是同步字幕。

视频以 2026-10-07 的一次真实运行为案例（macOS · OpenClaw · 微信 ClawBot），先讲体验，再讲能力：

- 收藏墙、信息流里的其他卡片是示意画面，画面中已标注。
- 那条小红书视频的封面、抽样帧、转写节选、微信回复和召回答复是实测原物或注明的节选。
- 等待过程（收件到回复约 6 分 11 秒）经过加速；画面认字为抽样帧，不是全片理解。

音乐为代码作曲的 MIDI，由 FluidSynth 和 MuseScore General 音色库（MIT）合成；标题字体为 Noto Sans SC（SIL OFL）。视频没有配音。

README 的四张图取自同一成片的静止帧。实际能力范围以 [v0.2 验证矩阵](../docs/v0.2-validation.md) 和 [v0.3 可靠性验收](../docs/v0.3-validation.md) 为准。来源素材的权利归原作者，本视频不构成再授权。

视频独立于运行包分发，安装 Source2Brain 不需要下载制作工程或媒体。
