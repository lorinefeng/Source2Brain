# Hermes 第二宿主验收

> 本文保留 v0.1.0 阶段的历史范围与证据，不作为当前安装或清理指令。当前默认视觉路线、真实验收和待办见 [v0.2 验证矩阵](v0.2-validation.md)。历史 OCR 成功不代表新版视觉链路已通过。

日期：2026-10-01。范围是 macOS arm64 上已有 Hermes 的 Skill/CLI 接入，复用当前模型。干净机器首次安装与微信迁移留在发布后的演示阶段。

## 环境与隔离

Hermes CLI 报告 v0.21.0（2026.8.31，upstream 78c7b9fd），本机源码 checkout 为 97f3229dfd；记录两者以免把版本横幅当作精确源码状态。Python 3.11.16、Node 26.8.1，当前模型 deepseek-v4-pro-0813。未升级 Hermes，未重新配置模型供应商。

使用独立 source2brain profile，只复制所需的现有模型配置与本机凭据；原默认 profile 不变，不复制聊天历史。完整 Skill 包安装到该 profile；使用 terminal/file/skills 工具集，通过 CLI 调用，不启动微信网关。

## 发现与修正

- 原 Skill 保存步骤强制调用 OpenClaw memory，已拆为宿主分支；缺少语义索引的宿主使用明确标注的文件检索。
- 文件检索需要短关键词／同义词，不能把整句提问作为字面匹配后就断言知识不存在。
- 模型创作中可能增加解释；Skill 要求区分作者引文、OCR 与当前模型建议，不把局部核验说成作者全部观点。
- Hermes 本机提示可选 tirith 扫描器不可用，仍使用自身命令模式检测；未为这次验收另装或关闭安全组件。

会话原始工具记录、输入、输出和哈希证据只留在运行端私有验收目录。公开报告不包含真实来源链接、个人路径、provider 地址或凭据。
