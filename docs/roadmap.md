## 首批用户上手后再做

- **宿主兼容：** 补 Hermes 的新来源全链路；按用户需求选择 WorkBuddy、Codex、Claude Code 等逐个实装，不把文档入口算作通过。微信参考入口仍使用单一 OpenClaw 绑定。
- **第二个能力包：** 优先考虑 MarkItDown 文档配方，用一份真实 PDF 或演示文稿验证安装、转换、来源映射、保存与回读。Karakeep、Anytype 继续保持候选，避免扩展数量先于可用性。
- **平台范围：** 核心 CLI 的 Linux 测试与真实浏览器采集分开；Windows/Linux 的登录、媒体处理和宿主常驻服务另行实测。
- **贡献门槛：** 给第三方配方补标准化样例、版本锁定、失败回执及验证模板，让贡献者交付可复现配方，而不只是项目链接。

通用安装器、独立 RAG 服务和更多存储后端暂不优先。先让首次安装成功、链接处理可靠、保存的知识能在新会话中带着证据用起来。
