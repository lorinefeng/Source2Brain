# 发布后干净演示的准备清单

这是待执行计划，不是卸载脚本。先完成公开版本发布，再讨论镜头和宿主，再执行清理与重装。

## 先盘点，后卸载

逐项记录实际路径、拥有者、是否由 Source2Brain 安装、是否被其他项目共用、备份位置、恢复方式：Source2Brain 仓库副本、Skill、独立 Node/OpenClaw runtime、media runtime、OpenClaw source2brain profile 和 LaunchAgent、Hermes source2brain profile、ASR 环境及模型缓存、浏览器桥接、知识库、微信绑定。

卸载范围只包括已经确认属于本项目的项目环境。知识库及帧证据先导出并核对哈希；不删除 Hermes 原配置、其他 Agent、浏览器用户目录、共用 Node/Python 或全局模型缓存。共享依赖如果保留，演示要说明这是“复用已有环境”，不能说成全新系统。

干净安装的证据是检测结果和从公开版本重新安装的过程，不是清空整台机器。建议专用演示 profile 与新知识库目录；实际卸载清单须在执行前核对到文件和服务。

## 微信与回退

微信通道按单一绑定准备。当前 OpenClaw 绑定若切换到 Hermes，预留本人重新扫码与收发验证步骤；原通道可恢复所需配置保留在私有备份。不要为录屏同时启动两个争用同一绑定的网关。

保存旧版本 Skill、配置和服务启动方式；失败恢复后先确认旧知识可读和原通道状态。不要把恢复旧环境后的成功剪辑成新安装成功。

## 成功条件

实际从公开 Release 获取安装资料和 Skill；缺失能力可被检测；按需装配可完成；新来源保存；新会话召回及带引用的工作应用；涉及微信则另有真实收发。失败和人工介入如实记入安装经验，再更新公开版本和视频台词。
