# v0.1.0 首发定义

> 本文保留 v0.1.0 阶段的历史范围与证据，不作为当前安装或清理指令。当前默认视觉路线、真实验收和待办见 [v0.2 验证矩阵](v0.2-validation.md)。历史 OCR 成功不代表新版视觉链路已通过。

更新：2026-10-01。首发定位为开发者预览版。先完成开源配套发布，再清理演示环境和制作视频；本轮推进到视频制作前讨论，不提前卸载运行端。

## 一句话与目标用户

**让你正在用的 Agent，把收藏变成有出处、用得上的知识。**

面向已经使用 Agent、愿意让它执行本机工具的个人用户。Source2Brain 负责把优秀开源项目整理成 Agent 能执行的配方：知道何时需要哪种能力、如何检测和复用、缺少时怎么安装、调用结果怎样留下证据。模型和对话仍由用户当前宿主提供。

最小可解释链路：收藏来源 → 按需求补能力 → 保存原文和证据 → 换一个会话找回 → 带引用用于当前任务。最后一步是按用户任务检索应用，不承诺自动监控所有工作或主动推送。

开源分发不包含账号、API key、浏览器登录、私有素材或模型权重。使用云端宿主模型时，交给模型的内容仍按该宿主的数据路径处理。

## 延后事项

- 粉丝全新机器完整上手与按需安装演示：开源发布后进行，不作为本轮已经完成的承诺。
- 通用一键安装器、全部宿主实测、Windows/Linux 采集、第二个能力包、独立 RAG 服务。
- 逐帧全片理解、图表关系或动作理解；OCR 只能保留抽样文字证据。
- 正式视频录制、Remotion 动画制作和视频平台发布：先讨论口播与画面分工。

## 发布与演示顺序

1. 固定首发内容，完成 Hermes 限定范围验证和文档。
2. 审核公开文件、运行测试、生成版本包和校验和，完成 GitHub 仓库及 Release 发布。
3. 与创作者讨论脚本、真人口播、Recordly 录屏和 Remotion 动画的占比与镜头。
4. 按约定清单备份并卸载 Mini 中本项目相关环境，保留知识与其他 Agent/账号；再从公开版本重装并录制。卸载操作另有明确清单，不使用全盘清理命令。
5. 修复录制中发现的安装缺口，必要时更新版本；最后锁定口播里的效果与兼容性措辞。
6. 完成动画、剪辑、字幕和成片，随后发布视频。

微信 ClawBot 通道按单一活跃绑定规划：当前 OpenClaw 绑定保留，切换 Hermes 演示时可能需要用户重新扫码。CLI 宿主验证与微信绑定验收分别记录，不因为 Hermes 能读库就宣称微信迁移完成。

## 公开表述

可以说：聚合成熟开源能力；基座轻、按需扩展；知识以文件保存；画面文字可追加追溯证据；兼容性有分级。

当前不能说：任何 Agent 一键即用；任何视频都能读懂；所有平台都已支持；安装成功率 80%；完全离线；无需登录；视频片段百分之百正确；已经完成干净环境从零安装演示。
