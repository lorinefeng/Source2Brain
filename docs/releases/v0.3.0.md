# v0.3.0：失败可解释，处理可恢复

链接处理失败后，Agent 现在可以说明卡在哪一步、保留了什么、接下来怎么继续。说“继续处理”时先校验并复用有效检查点；说“重发结果”时只补发已经保存的答复，不重新采集、转写或整理。

## 本次变化

- `SourceJob v1` 与 `job create/list/status/resume/record`，分别记录采集、附件、转写、抽帧、实际识读、整理、保存、索引和回复。
- 明确临时网络故障最多再试两次；登录、验证、昂贵超时、证据损坏与未知错误暂停。电脑或 Agent 重启后等待用户要求继续。
- 逐附件、逐帧/页保存进度；完整 ASR 结果可在中断后接管。已有音频成果不会因画面失败撤销，索引或回复失败不重跑上游。
- 回复先保存再发送；送达不确定不自动补发。实际消息工具报告成功与手机收件分别记录。
- 原子状态、哈希校验、执行锁、迟到结果拒绝及超时子进程清理；沿用现有宿主和微信绑定，不新增后台队列或基础依赖。

## 已验证与边界

127 项回归在维护端和 Mac mini 通过；CI 覆盖 macOS/Linux、Node 22/26。真实小红书下载受控故障后恢复、抖音约 32 分钟视频 ASR 落盘后中断恢复、两帧实际视觉识读恢复分别验收。微信受控索引故障后跨重置会话继续，手机确认完整收件；显式补发复用原答复，独立会话查回来源。62 个原知识/配置文件最终哈希一致。

本轮视觉恢复仅验证 2/24 帧，不代表整段视频已完成视觉理解。微信发送不确定由适配层测试覆盖，不冒充实际网络故障。平台与宿主支持范围沿用 v0.2.0；WorkBuddy 等资料级接入没有因此变成实装通过。详细证据见[可靠性验证](../v0.3-validation.md)。

## 安装与升级

下载 `source2brain-skill-0.3.0.tar.gz`、`Source2Brain-0.3.0.tar.gz`、`manifest.json` 和 `SHA256SUMS`。校验后让现有 Agent 按[安装指南](../installation.md)更新完整 Skill；不能只复制 SKILL.md。先等当前任务空闲，备份 Skill、工作区指令与项目配置，保留模型、登录态和微信绑定。

旧 SourceArtifact、SourceEnhancement 和普通命令继续兼容，不要求迁移原知识。新任务保存在当前知识库私有 `.source2brain/jobs/`，不参与检索、不进入发行包。回滚旧 Skill 时保留任务与来源，之后切回新版再继续。
