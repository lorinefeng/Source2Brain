# Source2Brain v0.1.0 开发者预览

让现有 Agent 把收藏整理成有出处、可找回的知识。首版提供基座、能力索引和已验证的 media 配方；按需使用成熟开源工具，知识默认存为普通 Markdown 文件。

## 本次内容

- SourceArtifact 与 SourceEnhancement：原文、转写、OCR、帧图、时间戳、引用和处理回执。
- 小红书采集／本地转写的 OpenClaw 参考部署；重复保存和人工批注保护。
- 可选 media：summarize 0.24.0 抽帧，Tesseract.js 7.0.0 中英文 OCR；不随基座默认安装。
- Hermes 第二宿主：复用现有模型，Skill + CLI 保存、正式知识库关键词检索、跨宿主读取画面证据。
- Codex、Claude Code、WorkBuddy、Qoder、DeepSeek Harness 官方接入资料与常见排障，未实装部分明确标注。

## 下载与使用

`source2brain-skill-0.1.0.tar.gz` 是完整 Skill 包；`Source2Brain-0.1.0.tar.gz` 是包括文档、测试与安装脚本的源码包。`manifest.json` 记录公开源文件哈希，`SHA256SUMS` 用于核对下载文件。素材、模型、账号与依赖运行目录不在包内。

在下载目录用 `shasum -a 256 -c SHA256SUMS` 核验全部资产。只下载部分资产时，核对 SHA256SUMS 中对应行，不把缺少其他文件误认为已下载文件损坏。

从 README 选择 Hermes 或 OpenClaw 参考路径；把说明交给自己的 Agent，让它先检测环境。Node 核心要求 22+，media 要求 24+；现有真实采集和宿主验收为 macOS arm64。Windows/Linux 的实际采集链路未验证。

## 验证与限制

维护端和 Mini 各 29 项 Node 测试通过。media 已有真实视频新增画面事实及新会话召回记录。Hermes 三个独立会话验证了真实知识回读、合成材料保存、重复保存保留批注；原来源 6 个文件与 Hermes 原配置未变。另一次独立 Skill 执行验证不完整材料进入 Pending 且不被正常检索召回。

Hermes 使用文件关键词检索，不能称为语义检索。首次真实链接采集未在 Hermes 重测，微信迁移没有验收。media 只覆盖抽样帧和 OCR，不等于全片视觉理解；没有可靠新增事实的结果保留 Pending。

粉丝全新环境安装与干净重装演示在开源后继续补齐；这不是“任意 Agent／任意视频一键即用”的正式版。其他能力包保持候选状态。当前已提供视频口播／分镜讨论稿，尚未制作视频。
