# v0.2.0：让链接进入下一次创作

2026-10-12。首个按明确支持范围交付的正式版本，接续 v0.1.0 开发者预览。

## 本版变化

- 抖音与小红书视频采集路由、平台独立 ID、登录和媒体完整性检测；失败材料保留为 Pending。
- 完整 Skill 携带脚本、安装资料、模板与配方，支持环境检测、依赖复用、隔离配置和安装失败恢复；新增本地 ASR 固定安装配方。
- SourceEnhancement v2：按需抽帧，调用已有多模态 Agent 或用户指定视觉工具，保存原帧、实际识图来源、时间戳和逐字证据。默认不安装 OCR 或视觉模型权重。
- 保留原笔记与人工批注；旧 OCR 证据可追加勘误，统一 read/search 使用有效校正并保留追溯。
- OpenClaw 可选微信常驻配方、Hermes 限定范围接入、WorkBuddy 官方资料级指引；README 增加 60 秒视频与关键帧。

## 已验证与支持边界

运行实测以 macOS arm64 为主。抖音、小红书各一条新视频已由真实微信投递，完成首次保存及完整回复，并由本人确认手机收件；分别独立 CLI 新会话召回通过。用户指定的视觉工具、历史一帧 v2 追加保存和新会话回读另行通过，不能合并称为新版视觉微信全链路验收。

核心测试及发布检查随版本验证。小红书多图微信、早期接收回执、全新用户安装、其他系统真实采集仍待完成；WorkBuddy 尚未实装。详见[验证矩阵](../v0.2-validation.md)和[路线图](../roadmap.md)。

## 下载与升级

从本版本 Release 下载 `source2brain-skill-0.2.0.tar.gz`、`Source2Brain-0.2.0.tar.gz` 和 `SHA256SUMS`。前者用于安装完整 Skill，后者包含运行源码、测试及文档；介绍视频单独提供，不随运行包下载。

升级前备份现有 Skill 与本项目配置，再按[安装指南](../installation.md)替换。保留知识库、共享模型、浏览器登录与现有微信绑定。v1 来源及旧增强保持兼容，默认画面处理采用 v2；无需为升级重写已保存笔记。

本项目组合 Agent-Reach、OpenCLI、FunASR、summarize 等上游能力；模型和登录态由用户准备，详见[上游致谢](../../THIRD_PARTY_NOTICES.md)。
